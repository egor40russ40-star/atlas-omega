# Этап 17 — Программистская клавиатура и модель ввода

Статус: ARCHITECTURE ONLY. APK не собирается.

## Цель

Сделать ввод команд и кода с телефона быстрым настолько, чтобы терминал был пригоден для длительной работы, а не только для аварийного администрирования.

## Базовый принцип

Экранная клавиатура Android остаётся источником обычного текста. ATLAS добавляет над ней собственную терминальную панель, которая отправляет корректные terminal key sequences и modifiers непосредственно в активную PTY-сессию.

## Режимы панели

Панель имеет 3 слоя:

1. BASIC — ESC, TAB, CTRL, ALT, стрелки, HOME, END.
2. CODE — символы программирования: |, \\, ~, _, -, =, :, ;, ', ", `, {}, [], ().
3. SHELL — CTRL+C/D/Z/L/R/A/E/W, PGUP/PGDN, history up/down, clear.

Пользователь может переключать слой свайпом или кнопкой, а порядок клавиш хранится как профиль.

## Модификаторы

CTRL/ALT/SHIFT работают не как текстовые макросы, а как состояние ввода:

- один tap — применяется к следующей клавише;
- double tap — lock;
- long press — удержание до отпускания;
- визуальный индикатор показывает активный modifier;
- после отправки одиночный modifier автоматически сбрасывается.

## Аппаратная клавиатура

Bluetooth/USB-клавиатура должна работать без отдельного режима приложения. KeyEvent переводится в terminal sequence с учётом CTRL/ALT/SHIFT и раскладки.

## Русская раскладка

UI приложения русский, но терминальный ввод не должен насильно транслитерировать команды. Пользователь может мгновенно переключать системную раскладку Android. Панель служебных клавиш остаётся одинаковой при RU/EN.

## Safe input

Критическое правило: вставка текста и выполнение команды — разные действия.

- Paste: передаёт текст без Enter.
- Run: передаёт текст и Enter только после явного действия.
- Многострочный paste показывает краткое подтверждение или режим bracketed paste при поддержке shell.

## Скорость ввода

Для часто используемых символов исключается необходимость переходить в системные символы Android. Допускаются:

- long-press варианты клавиши;
- повтор при удержании стрелок/backspace;
- haptic feedback опционально;
- пользовательские размеры кнопок;
- compact mode для маленького экрана.

## Тесты

Обязательны unit/integration проверки exact byte sequences для ESC/TAB/arrows/function keys/modifiers, UTF-8, bracketed paste и hardware keyboard.
